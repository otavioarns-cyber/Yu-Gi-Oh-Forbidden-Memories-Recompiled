# MOD Efeitos de Cartas Rituais

Branch exclusiva: `mod-ritual-effects`.

Esta area mantem o MOD separado da `master`, de `mod-field-effects` e dos fontes oficiais. A versao atualmente em desenvolvimento e a v0.74 test/optimization, baseada na v0.73 funcional aprovada para Black Chaos.

Estrutura:
- `dev/`: estado atual em desenvolvimento.
- `versions/`: snapshots importantes preservados.
- `docs/`: regras, arquitetura, decisoes tecnicas, bugs conhecidos e resultados de testes.

Nao editar arquivos de outros MODs a partir desta area.
